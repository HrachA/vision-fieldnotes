Study guide

Field notes

From pixels to distance

Flatten a 28 × 28 image into 784 numbers. Manhattan distance sums the absolute differences between corresponding pixels. Euclidean distance squares those differences, sums them, and takes the square root.

Try it. Switch between L1 and L2 on the same query. Do the closest images change even when the prediction stays the same?

From neighbors to a label

One neighbor gives a single training example the deciding vote. A larger k lets several handwriting styles contribute. A majority can also outvote a genuinely close match.

Try it. Set k to 1, then 9. Shift the query three pixels to the right. Which reference strokes still line up?

Evaluate on unseen digits

Choose k and the distance metric on validation data. Keep the test set separate until those choices are fixed. A score on those held-out examples estimates how well the chosen model generalizes.

Try it. Compare two settings using the same set of digit queries. Keeping the inputs fixed makes it easier to see the effect of the hyperparameter.
